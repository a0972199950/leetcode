# 219. Contains Duplicate II

- **難度**：Easy
- **連結**：https://leetcode.com/problems/contains-duplicate-ii/
- **標籤**：Array, Hash Table, Sliding Window

## 題目描述

Given an integer array `nums` and an integer `k`, return `true` _if there are two **distinct indices** _`i`_ and _`j`_ in the array such that _`nums[i] == nums[j]`_ and _`abs(i - j) <= k`.

## 範例

**Example 1:**

```
Input: nums = [1,2,3,1], k = 3
Output: true
```

**Example 2:**

```
Input: nums = [1,0,1,1], k = 1
Output: true
```

**Example 3:**

```
Input: nums = [1,2,3,1,2,3], k = 2
Output: false
```

## 限制條件

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= k <= 10^5`
