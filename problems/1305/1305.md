# 1305. All Elements in Two Binary Search Trees

- **難度**：Medium
- **連結**：https://leetcode.com/problems/all-elements-in-two-binary-search-trees/
- **標籤**：Tree, Depth-First Search, Binary Search Tree, Sorting, Binary Tree

## 題目描述

Given two binary search trees `root1` and `root2`, return _a list containing all the integers from both trees sorted in **ascending** order_.

## 範例

**Example 1:**

![](https://assets.leetcode.com/uploads/2019/12/18/q2-e1.png)

```
Input: root1 = [2,1,4], root2 = [1,0,3]
Output: [0,1,1,2,3,4]
```

**Example 2:**

![](https://assets.leetcode.com/uploads/2019/12/18/q2-e5-.png)

```
Input: root1 = [1,null,8], root2 = [8,1]
Output: [1,1,8,8]
```

## 限制條件

- The number of nodes in each tree is in the range `[0, 5000]`.
- `-10^5 <= Node.val <= 10^5`
